## SQA-01

QA на v85 подтвердил: `#expense` не отмечал активный видимый раздел. На v86 панель по-прежнему выбирается по target, а навигация — по `navTarget=journal` для expense. `driverPanelExpense` подписан видимой вкладкой `driverTabJournal`; её `aria-controls` динамически указывает на expense/journal по текущей панели. Маршруты и бизнес-операции не менялись.

В реальном Edge v86 проверены:

1. Главная → форма расхода: активна единственная видимая вкладка «Расходы», tabindex 0, controls=driverPanelExpense, labelledby=driverTabJournal, фокус expenseAmount.
2. Нажатие «Расходы» открывает историю и восстанавливает controls=driverPanelJournal.
3. Back возвращает форму и сумму `12,345`; Forward возвращает историю с правильной ARIA-связью.
4. ArrowRight из формы через видимую вкладку ведёт к «Сообщениям» и фокусирует driverTabMessages.

Регрессионный Node-тест покрывает expense → history → home → expense, единственную активную вкладку, tabindex, ARIA и видимую панель. Итоговый повтор SQA-01 остаётся за независимым QA; его документ разработкой не редактировался.
