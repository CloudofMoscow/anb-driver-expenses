### Сопоставимые замеры F09

Node 24.19.0, loopback, медиана трёх полных запросов после прогрева, синтетические клоны одного исторического рейса с расходом. Исходный сервер берётся скриптом из фиксированного `c0443fe`, исправленный — из рабочего дерева; отдельные временные копии одной demo-data. Время включает получение и распаковку ответа, **не включает DOM**.

| Рейсов | Офис prepare до → после | Офис медиана, мс до → после | JSON без сжатия, байт | Gzip, байт | Неизменённый polling |
| --- | --- | --- | --- | --- | --- |
| 100 | 356 → 57 | 29,06 → 26,24 | 417629 | 18055 | 304, 0 байт, 3 prepare |
| 1000 | 3056 → 57 | 159,05 → 93,30 | 3815109 | 56058 | 304, 0 байт, 3 prepare |
| 5000 | 15056 → 57 | 739,39 → 519,25 | 18935089 | 211335 | 304, 0 байт, 3 prepare |

У водителя при 5000 рейсах: 5004 → 9 prepare; 209,28 → 168,15 мс; 7395976 байт JSON → 92749 байт gzip. У неизменённого polling обеих ролей — 3 prepare независимо от истории. В данном запуске офисный 304 при 5000 занял 5,84 мс.

Полный отчёт при 5000 сохранил 8 prepare; 290,18 → 353,07 мс, gzip 126328 байт вместо 12607344 без сжатия. Сжатие и локальная нагрузка добавляют CPU: ускорение каждого отдельного запроса не заявляется. Повторная загрузка отчёта вне открытой доходности устранена. Синтетические повторяющиеся строки сжимаются лучше реальных уникальных данных.

## Ограничения и остатки для независимого QA

- Production-база не открывалась. API-тесты используют временные SQLite и базы в памяти; браузер — отдельную временную копию demo-data на loopback. Публичные демопароли и тестовые PNG использованы как фикстуры. Аномалии искусственных дат/одометра ожидаемы.
- Стек, зависимости, финансовые правила, схема БД и JSON-контракты сохранены. Пагинация не вводилась. Первоначальный полный JSON и DOM всё ещё растут вместе с историей; при любом изменении ревизии bootstrap передаётся целиком. Дальнейшая инкрементальная загрузка требует отдельного решения по контракту.
- PWA обновлён до `anb-fleet-v82`, версии проставлены также импортируемым модулям. Это предотвращает получение старой логики из HTTP-кэша; все используемые модули включены в precache. Проверен браузерный переход между версиями в этой сессии. Установка PWA на реальном устройстве не проверялась.
- Не проверены физические iPhone/Android, Safari/Firefox, реальная камера, клавиатура устройства, геопозиция, push на заблокированном телефоне, настоящий режим самолёта, конкурентная нагрузка, Web Vitals и длительный soak-test. Перепроверка offline на устройствах и всей матрицы отказов остаётся за независимым QA.
- Нужен повторный независимый прогон всех F01–F12 на итоговом общем diff, в том числе CSS дизайна. Эта запись не заменяет исходный аудит и не означает выпуск продукта.
