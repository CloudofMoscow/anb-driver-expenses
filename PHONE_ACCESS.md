# Как открыть ANB на телефоне

## Быстрый способ для просмотра и тестирования

1. Подключите ноутбук и телефон к одной Wi-Fi сети. Мобильный интернет на телефоне лучше временно отключить.
2. При первом запуске дважды нажмите `allow-phone-access.cmd` и подтвердите запрос Windows. Этот шаг открывает только порт ANB `8788` и только для устройств локальной сети.
3. Дважды нажмите `start-phone-demo.cmd` в папке проекта.
4. Не закрывайте появившееся чёрное окно.
5. В окне появится адрес наподобие `http://192.168.1.12:8788` — откройте именно его в браузере телефона.
6. Если Windows дополнительно спросит о сетевом доступе Node.js, разрешите только частные сети.

Текущий адрес ноутбука может изменяться после перезагрузки или подключения к другой сети. Поэтому используйте адрес, который показан в окне при каждом запуске, а не сохранённую старую ссылку.

## Тестовые учётные записи

- Офис: `owner` / `anb-demo-2026`
- Водитель: `driver1` / `driver-demo-2026`

## Если страница не открывается

Проверьте по порядку:

1. На ноутбуке ссылка из чёрного окна должна открываться в браузере.
2. Телефон не должен быть подключён к гостевой Wi-Fi сети: такие сети часто изолируют устройства друг от друга.
3. VPN и прокси на ноутбуке и телефоне нужно временно отключить.
4. В брандмауэре Windows должен быть разрешён входящий TCP-порт `8788` для частной локальной сети.
5. После изменения правила закройте окно сервера и снова запустите `start-phone-demo.cmd`.

## Ограничение локального способа

Обычный адрес `http://...` подходит для просмотра интерфейса и проверки основных форм. Установка полноценной PWA, push-уведомления и геолокация в мобильных браузерах требуют защищённого адреса HTTPS. Для постоянной эксплуатации приложение нужно будет разместить на сервере с доменом и HTTPS; локальный запуск предназначен для разработки и демонстрации.
